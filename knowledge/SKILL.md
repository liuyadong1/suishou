# 摄影知识蒸馏 → 拍照辅助规则库

目标产品：面向不懂摄影的普通人的相机App（项目名"随手"），取景时实时检测画面，用**简易图形 + 一句短文案**给出构图、光影、姿势建议。本 skill 负责把摄影书的知识变成 App 能直接执行的规则，并维护规则库 `photo_rules.json`。

## 一、何时使用
- 用户上传新的摄影书/教程/文章，要"蒸馏""提炼成规则"
- 给规则库新增场景（如美食、宠物、夜景人像）或调整阈值
- 审核规则是否冲突、过时、普通人能否照做

## 二、工作流程
1. **通读并列原理清单**：按章节记下每条可操作的原理，标注出处（书ID·章节·小节）。用自己的话改写，不照抄原文。
2. **筛选**（每条原理过三关，任一不过就降级到 `excluded_from_book` 或只进 skill 文案参考）：
   - 能实时检测吗？→ 必须能映射到 `signals` 里的信号（或明确新增一个可实现的信号）
   - 普通人一步能照做吗？→ 提示必须是"挪、蹲、点、开/关、等"这类单一动作
   - 现在还成立吗？→ 老书结论按当前手机能力修正（HDR、夜景、人像虚化、微距镜头）
3. **写成规则**（结构见第三节），先查重：已有同类规则就合并——在原规则 `source` 末尾用“；”追加新出处、必要时扩展 `scenes` 或把 low/medium 升级，不新建重复规则。
4. **处理冲突**：同一画面可能同时触发多条，用 `priority` 和 `suppresses` 处理；"有意为之"的情况写豁免规则（如中央构图豁免、剪影豁免逆光补光）。
5. **校验**（必须跑）：ID唯一；`when` 用到的信号都已在 `signals` 声明；`overlay.type` 都在 `overlays` 里；`tip` ≤18字；`suppresses` 指向存在的ID。
6. **输出**：更新 `photo_rules.json`（版本号+1，`source_books` 增加书目），附一段变更说明：新增/修改/排除了哪些、为什么。

## 三、规则结构
```json
{
  "id": "COMP-003",               // 前缀：STAB/FOC/EXP/LGT/COMP/POR/GRP/KID/PET/SPT/ARC/INT/FOOD/FLW/NGT/BW/CRE，后期用 POST
  "category": "composition",
  "scenes": ["*"],                // 或 landscape|portrait|selfie|group|child|pet|plant_flower|food_still|building|interior|street|sports|night|water|macro
  "when": {"all": [["subject_dist_to_center", "<", 0.08]]},   // all/any；运算符 == != < <= > >= in in_range_any
  "problem": "小主体放在正中，画面呆板",     // 给开发和审核看
  "overlay": {"type": "target_point", "params": {"target": "nearest_third_point"}},
  "tip": "把主角移到交叉点上",             // 给用户看，≤18字，口语，动作在前
  "priority": 3,
  "detectability": "realtime",     // realtime | needs_depth | needs_model | metadata
  "confidence": "high",            // high | medium | low
  "note": "可选：阈值依据、例外、机型差异",
  "source": "B1·构图中·井字形",
  "suppresses": ["..."]           // 可选
}
```

**优先级**：1 拍糊风险（抖、跑焦）→ 2 曝光光线硬伤 → 3 构图主要问题 → 4 构图用光优化 → 5 创意/机会提示。
**显示策略**：屏幕上最多2个图形、1条文案；画面稳定8帧后才提示；同一规则冷却4秒；用户关掉后静默2分钟。宁可少提示，不要满屏。

**图形库**（新增图形要谨慎，优先复用）：level_line 水平仪、thirds_grid 九宫格、target_point 目标点、move_arrow 移动箭头、focus_box 对焦框、ev_hint 曝光加减、sun_icon 绕光方向、hand_shield 挡光手势、symmetry_axis 中轴线、diagonal_guide 对角/分割线、frame_highlight 画框高亮、height_icon 举高/放低、distance_hint 靠近/后退、steady_icon 握稳、burst_icon 连拍、hdr_toggle HDR开关、bw_preview 黑白预览、pose_silhouette 姿势剪影、turn_hint 侧身转头示意、eye_line 眼睛目标线、group_triangle 三角站位、banner 纯文案。

## 四、文案规范
- 动作在前，原因在后或省略："蹲低一点，平视或仰拍"，不写"建议您尝试降低拍摄高度"
- 不用术语：不说"测光""曝光补偿""景深"，说"点一下暗处""调亮一点""背景会虚掉"
- 机会类提示用鼓励语气（"黄金时刻，多拍几张"），问题类提示不指责
- 有意的艺术选择不纠正：倾斜≥10°、剪影、拍光晕被多次忽略 → 不再提示

## 五、已蒸馏的核心原理（用于新规则查重与文案参考）

### B1《10天学会手机摄影》
**稳与清**：握稳/借力靠墙；暗光不拍动的东西或用连拍；对焦点在主体，人像对眼睛；纯色区域对不上焦就先对等距物体再锁定；离太近对不上焦就退后再放大。
**曝光**：点哪里按哪里测光——逆光主体黑就点主体；白多调亮、黑多调暗（白加黑减）；明暗差大开HDR，有运动物体关HDR。
**光线**：正午硬光进阴影或遮光；顺光平，侧光逆光有层次；树叶花瓣逆光透亮；阳光入镜用手挡；日出日落前后是最佳时段；阴天雨后拍花颜色最正；避开偏色灯光；窗边明暗分割光有戏剧感；逆光暗主体可转做剪影。
**构图**：先有主题和主角；做减法让画面简洁；三分法（地平线放1/3处，天空好看多留天）、主体放交叉点；主体大且背景干净时中央构图成立；对称要站正中轴，可用小元素打破对称；汇聚线放低机位；S形、对角线、三角形（侧面拍矩形）增加动感立体感；门窗树枝做画框；大留白时主体放三分线；远近对比对焦近处；换角度——蹲低平视或仰拍；避免前景挤占主体；能走近就少用数码变焦。
**人像**：避开硬光，树荫或背光；黄金时刻侧逆光让发丝发亮；背景干净；"摆抓"——给动作在动态中抓拍；自拍镜头略高于脸；人小景大的背影有意境。
**黑白与创意**：颜色杂乱、强光影、重复图案适合黑白；手机稳时可拍光轨、流水、延时；跳跃抛洒用连拍。
**后期思路**（只作拍后建议）：先裁剪去边缘杂物→整体明暗→局部提亮主体→适度饱和度/色温→暗角或虚化收视线。

**B1已排除**：主观审美与修养类内容；具体软件界面步骤；过时机型与软件推荐；有损设备的偏方（如滴水当微距镜头）；无依据说法（"露左脸更好看"）；"HDR不适合人像"等对现有手机已不成立的结论。

### B2《美国纽约摄影学院摄影教材》（上下册，只取与手机取景相关章节）
**眼力**：同样三原则（主题/引导注意/简洁）；精彩瞬间先拍下再完善构图；不在关节处裁切；用“外地游客”的眼光看身边。
**构图突出主体**：初学者最常见毛病是站太远；画框（树干、门洞、前景人物）是调味品；主体亮、周围暗最抓眼；重复与倒影；周围人视线指向主体；常见错误——取景太满、头上长树、近距离透视变形、手指挡镜头；脸朝向/运动方向多留空。
**对焦与快门**：对焦在故事最重要处；离越近越要准；景深=光圈/距离/焦距；横穿画面最难凝固、迎面最易；追随拍出速度感；高速快门冻结浪花、慢门成丝绢。
**特殊曝光**：夜景灯光、月亮会被拍过曝→调暗；烟花要稳、避开前景亮灯；高反差数码保高光。
**自然光与现场光**：户外人像别让人对着太阳眯眼→多云、整片阴影、侧对太阳+反光；树荫光斑落脸上要避开；阴影偏蓝；清晨低角度金光与轮廓光；室内窗光/台灯有氛围，让阴影黑下去、别硬提亮。
**人像**：镜头与眼睛同高；仰拍显傲慢、俯拍显忧郁（可藏双下巴）；用中长焦、离≥1.2米防大鼻子；四分之三侧脸最讨好（身体斜45°头转回，远侧耳朵刚好看不见）；正面端肩像证件照；脸朝向一侧多留空，眼睛约在上三分之一；头发与背景要有明暗分离；眼镜反光→低下巴或换角度；表情靠聊天放松，别喊“笑一笑”；修饰原则——离镜头近显大、亮部显大。
**实景人像**：用环境和道具讲“这是什么人”；背景简洁、去掉烟灰缸乱文件；多云光平→从一侧加方向光；彩色墙会把颜色映到脸上。
**合影/儿童/宠物**：合影要统一（看同一点、紧挨、三角形高低错落）；亲子照孩子看镜头大人看孩子；蹲到孩子/宠物眼睛高度；按年龄逗引、拨浪鼓在镜头旁晃、叫名字只灵一两次；黑毛减曝光白毛小心过曝；背景与毛色要有对比；宠物至少一张脸部近照。
**建筑**：竖线要竖直——端平、后退或站到半高处，故意仰拍要够明显；别正对楼角让两面一样大；近距离广角拍楼角会变“船头”；横向挪步避开电线杆车辆；室内物件越少越好、广角拍室内要端平；空白天空少拍、等云和太阳。
**花卉/食品**：花近拍先选好对焦点，有风等风停；背景别与花同色；食物用侧后方光显质感，喷点清水显新鲜。
**体育**：快门够快、连拍；把动作拍大；拍朝你来的动作；预判下一个动作位置；闯入者会抢焦→锁定对焦；赛后表情也是好画面。
**数码**：看直方图别只看小屏；放大检查清晰度；自动白平衡大多够用但日落别被校掉暖色；半按预对焦减少快门时滞。

**B2已排除**：胶片/暗室/区域系统；机背相机移轴、多灯光比、闪光同步；人体魅态；摄影室经营与广告业务；食品涂甘油、昆虫放冰箱等不适合普通用户的做法。

## 六、新书蒸馏时的注意
- 多本书说法冲突：写一条规则，`note` 里标明分歧，`confidence` 降为 medium
- 阈值是经验初值，标 `note` 提醒需用真实样片调参；不要声称已验证
- 每本书单独一个 `source_books` ID（B2、B3…），出处可追溯
- 只提炼原理，不复制原文段落或书中图片
- 大部头/扫描版：先OCR目录，只精读与手机取景相关的章节（构图、光线、人像、场景对策、数码使用），器材/暗室/商业章节跳过并记入排除
- 当前规模：v0.2.0 共96条取景规则、8条拍后建议，来源B1+B2
